Bengaluru Optimal Route Finder is an interactive city map app. You can enter two locations in Bengaluru and see the best route on the map. It does more than just find a route. It compares standard A* with a custom bidirectional A* using a real OpenStreetMap road network that has over 150,000 nodes. The routes are shown in different colors, and a live stats panel displays: • Total distance of the trip • Time taken by each algorithm • Number of nodes explored by standard A* • How many times faster the bidirectional A* was With one click, you get directions across Bengaluru. You also see a real-time visual demo of pathfinding algorithms competing in a real city.
